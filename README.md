## 这是什么？

一个**不依赖具体任务、不自带程序运行环境**的 AI 技能说明包。用户只要把 `SKILL.md` 交给支持读取文件的 AI，就可以开始由 AI 主动询问需求，并逐步建立“目标 → 观测 → 分析 → 调整 → 验证 → 阶段报告”的工作方式。

不同于完整版，本轻量包**不包含** Python 控制引擎、PID/MPC/Kalman 的可运行代码、网页 UI、数据库、定时器、自动通知或外部 API。需要这些功能时，交由用户的 AI 根据具体场景、可用工具和授权自行开发或集成；**不要声称只导入 SKILL 就能后台运行**。

## 包内只有四个文件

| 文件 | 用途 |
|---|---|
| `SKILL.md` | AI 的主指令：能力判断、渐进式访谈、量化建模、执行与反馈规则 |
| `README.md` | 这份使用说明；包含可以直接复制的启动指令 |
| `LICENSE` | 自定义署名使用条款 |
| `NOTICE` | 作者和来源信息 |

## 用户只拥有普通聊天 AI 时

1. 上传 `SKILL.md`（或者整个 ZIP，前提是 AI 能读取压缩包）。
2. 向 AI 发送下方的**启动指令**。
3. AI 应先询问缺失的关键资料，尽量一轮只问一两个问题，然后给出容易理解的目标及观测计划。
4. 用户日后提供新数据时，AI 继续分析；如无法持久保存记录，可要求 AI 导出最新的计划 JSON，下次对话重新上传。

**启动指令（可直接复制）：**

> 请读取我上传的 FCC Lite `SKILL.md`，严格按照它的要求工作。先判断你能使用哪些工具，不要假装已安装程序、能够后台监控或定时主动联系我。请围绕我想实现的目标，逐步询问你尚缺少的信息，包括：目标及衡量方法、已有数据和数据来源、采集/评估/汇报/验证节拍、可调整因素、风险和执行授权。每轮只问最重要的一到两个问题；已知内容不用重复问。信息足够后先给我一份通俗的反馈计划和可导出的 JSON，经我确认再启动当前环境真正支持的工作；其他功能可按需要自行衍生，但必须实际测试并说明限制。

## 用户使用可执行代码的 AI Agent 时

在上述流程之外，AI **可以**按需要创建轻量脚本、界面、任务调度、数据读写与报告工具。它应先核实本地权限与数据接入条件，并取得用户对安装/联网/写操作的授权，再实施。**不强制使用任何语言、数据库或框架**。

如果需要完整的现成数学控制引擎、Web UI 或 API，可另行使用 FCC Control Studio 完整版；本包不要求它一定存在。

## AI 最少要问清楚什么？

- **目的与达标条件：** 最终想改善什么，如何判定成功。
- **观察依据：** 日常输入/观测是什么，现状或基线是多少，数据是否可靠。
- **四种节拍：** 多久采样、多久分析、多久汇报、调整后多久才能判断效果。
- **可改变什么：** 哪些调整可行，哪些限制不能突破，需要谁批准。
- **运行与送达：** 谁提供下一次数据、记录保存在哪里、报告会出现在哪里。

其他参数由 AI 按任务复杂度自行追问和生成。没有足够依据时先观察，**不为了使用高级算法而使用高级算法**。

## 重要限制

- 只有聊天窗口，通常无法保证在用户离开后持续工作或主动发送报告。
- 自己生成的代码应经过实际运行测试；“写出代码”不等于“已经部署”。
- 只提出建议不算执行，执行前后对比也不必然证明因果关系。
- 面向高风险系统，需人工审批和独立安全措施。
- 使用或再分发请遵守 `LICENSE` 和 `NOTICE` 中的来源署名要求；本许可证为**自定义 Source-Available 许可**，不是 OSI 标准开源许可证。
